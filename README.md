# 꿈 채움 카드 (Dream Card)

빈칸에 꿈을 적거나 사진을 올리면 **9:16 세로 카드(1080×1920)** 로 다시 그려 주고,
적은 내용에 어울리는 **오늘의 명언** 한 문장과 우산 쓴 고양이의 "화이팅!" 응원을 함께 담아 주는 웹앱입니다.

- 카드는 브라우저 안의 Canvas로 그려집니다. 사진은 서버로 올라가지 않습니다.
- 서버·데이터베이스·API 키가 전혀 필요 없어 Vercel 무료 플랜으로 그대로 돌아갑니다.

## 필요한 것

Node.js 18.18 이상 (20 이상 권장)

## 로컬에서 실행하기

```bash
npm install
npm run dev
```

http://localhost:3000 을 열면 됩니다.

## Vercel에 배포하기

### 방법 1 — GitHub 연동 (권장)

1. 이 폴더를 GitHub 저장소로 올립니다.
   ```bash
   git init
   git add .
   git commit -m "꿈 채움 카드"
   git branch -M main
   git remote add origin https://github.com/<계정>/dream-card.git
   git push -u origin main
   ```
2. [vercel.com/new](https://vercel.com/new) 에서 그 저장소를 선택합니다.
3. 프레임워크가 **Next.js** 로 자동 인식됩니다. 설정을 바꿀 것 없이 **Deploy** 를 누르면 끝입니다.

이후에는 `git push` 할 때마다 자동으로 다시 배포됩니다.

### 방법 2 — Vercel CLI

```bash
npm i -g vercel
vercel          # 미리보기 배포
vercel --prod   # 실제 도메인으로 배포
```

### 도메인 연결

Vercel 프로젝트 → Settings → Domains 에서 `dream.nolstay.com` 같은 주소를 연결할 수 있습니다.

## 사진 넣기 — 어떤 비율이든 전부 보이게

네모칸(정사각)에 9:16 세로 사진이나 16:9 가로 사진을 넣어도 잘리지 않습니다.

- **전체 담기 (기본)** — 사진 전체가 다 보이도록 맞춥니다. 남는 여백은 같은 사진을 크게 깔아
  흐리게 처리한 배경으로 채워 빈 흰 여백이 생기지 않습니다. 꿈 문장이 있으면 사진 아래에
  따로 마련한 띠에 들어가므로 사진 위를 덮지 않습니다.
- **꽉 채우기** — 네모칸을 빈틈없이 채우고 바깥쪽을 잘라냅니다. 문장은 사진 위 그라데이션 위에 올라갑니다.

사진을 올리면 두 방식을 고르는 버튼이 나타나고, 파일 이름 옆에 인식된 비율(9:16 세로 등)이 표시됩니다.

## 테스트

사진 맞춤 동작은 실제 브라우저에서 자동 검증합니다. 네 모서리에 서로 다른 색 표식을 넣은
테스트 이미지(9:16 · 16:9 · 1:1 · 4:1 초광각 · 1:3 세로장)를 실제로 업로드한 뒤,
카드 위 그 좌표의 픽셀 색을 읽어 네 모서리가 모두 살아 있는지 확인합니다.

```bash
npm run build
npm start                 # 다른 터미널에서 실행해 두고
npm i -D playwright sharp # 처음 한 번만
npm run test:fixtures     # 테스트 이미지 만들기 (fixtures 폴더가 이미 있으면 건너뛰어도 됩니다)
npm run test:fit          # 사진 맞춤 검증
npm run test:save         # 저장 검증
npm run test:text         # 100자 표시 검증
npm run test:copy         # 이미지 복사(클립보드) 검증
npm run test:mobile       # 휴대폰 환경(카톡 인앱 포함) 검증
```

`test:fit` 은 `tests/shots/` 에 비율별 결과 카드를, `test:save` 는 `tests/downloads/` 에
실제로 내려받은 PNG를, `test:text` 는 `tests/shots-text/` 에 100자 카드를 남깁니다.
저장 테스트는 파일이 실제로 내려받아지는지와 1080×1920 정상 PNG인지까지 확인하고,
100자 테스트는 카드에 그려진 글자를 그대로 읽어 원래 문장과 한 글자씩 대조합니다.

## 꿈 문장 — 100자까지

꿈 문장은 100자까지 적을 수 있고, 그 100자가 카드에 한 글자도 빠짐없이 들어갑니다.
입력창 오른쪽 위에 지금까지 적은 글자 수가 표시되며 100자를 넘기면 더 입력되지 않습니다.

카드에서는 글자 크기와 줄 수가 길이에 맞춰 자동으로 조절됩니다. 짧은 문장은 70px로 크게,
100자를 채우면 사진 없는 카드는 50px 일곱 줄로, 사진이 있는 카드는 32px 다섯 줄로 담깁니다.
사진과 함께 쓸 때는 문장이 길어진 만큼 아래 띠가 늘어나므로 여전히 사진을 덮지 않습니다.

## 저장 · 복사 · 공유 — 세 가지 방법

**이미지 저장** — 완성된 카드를 1080×1920 PNG 파일로 내려받습니다. 브라우저가 다운로드를 막는
환경에서는 버튼 아래에 완성 이미지가 그대로 나타나므로, 휴대폰에서는 길게 눌러, PC에서는
오른쪽 클릭해 저장하면 됩니다.

**이미지 복사** — 카드 이미지 자체를 클립보드에 넣습니다. 카카오톡 대화창이나 한글·워드 문서에서
**Ctrl+V** 로 바로 붙여넣을 수 있습니다. PC에서 카톡으로 보낼 때 가장 편한 방법입니다.
(클립보드 이미지 복사를 지원하는 브라우저에서만 버튼이 보입니다. 크롬·엣지·사파리는 됩니다.)

**공유하기** — 기기의 공유창을 엽니다. 휴대폰에서는 사진첩에 바로 저장하거나 카카오톡·인스타그램으로
보낼 수 있습니다. 윈도우 PC에서도 이 버튼이 뜨지만, 윈도우 공유창은 카카오톡으로 파일을 넘기지 못하는
경우가 많습니다. PC에서는 **이미지 복사**나 **이미지 저장**을 쓰시는 편이 확실합니다.

이 버튼은 어떤 브라우저에서도 숨기지 않고 항상 보여 줍니다. 공유 기능이 없는 환경에서는 눌렀을 때
되는 방법을 차례로 시도합니다. 이미지 파일 공유가 되면 그것으로, 안 되면 페이지 주소 공유로,
그것도 안 되면 완성된 카드 그림을 화면에 띄우고 길게 눌러 사진첩에 저장하도록 안내합니다.

## 카카오톡 안 브라우저에서 열었을 때

카카오톡 대화방의 링크를 눌러 들어오면 카카오톡 자체 브라우저로 열립니다. 이 브라우저는 저장·공유·복사
기능을 제공하지 않아 카드를 내보낼 수 없습니다. 인스타그램·네이버 앱·페이스북·라인도 마찬가지입니다.

그래서 이런 환경을 감지하면 화면 맨 위에 안내를 띄웁니다. 오른쪽 위 메뉴에서 "다른 브라우저로 열기"를
눌러 크롬이나 사파리로 열면 모든 기능이 정상 동작합니다. 감지 규칙은
`components/DreamCardStudio.js` 의 `setInApp` 부분에 있습니다.

## 폴더 구조

```
app/
  layout.js      웹폰트 연결, 페이지 제목·설명(공유 미리보기)
  page.js        첫 화면
  globals.css    전체 스타일 (밝은 모드·어두운 모드 색상 포함)
components/
  DreamCardStudio.js   입력 폼, 사진 업로드, 미리보기, 저장·공유
lib/
  draw.js        카드 한 장을 캔버스에 그리는 코드 (fitRect 가 사진 맞춤 계산)
  quotes.js      주제별 명언 은행과 문장 고르는 규칙
tests/
  fit.test.js       사진 맞춤 자동 검증
  save.test.js      저장 자동 검증
  text.test.js      100자 표시 자동 검증
  copy.test.js      이미지 복사 자동 검증
  mobile.test.js    휴대폰 환경(카톡 인앱·공유 미지원) 자동 검증
  make-fixtures.js  테스트용 비율별 이미지 생성
  fixtures/         만들어진 테스트 이미지
```

## 자주 바꾸게 되는 것들

**명언 추가·수정** — `lib/quotes.js`
카테고리의 `q` 배열에 `["문장", "출처"]` 를 넣으면 됩니다.
`k` 배열은 그 주제로 분류할 키워드입니다. 예를 들어 숙박업 문구를 늘리려면 `business.q` 에 추가하세요.

**새 주제 만들기** — `lib/quotes.js` 에 아래 형태로 항목을 하나 더 추가합니다.

```js
wedding: {
  label: "결혼 · 예식",
  k: ["결혼", "웨딩", "예식"],
  q: [["둘이 걸으면 길이 짧아진다.", "동양 격언"]],
},
```

**서명·꼬리말 문구** — `components/DreamCardStudio.js` 아래쪽의 `.foot` 부분과,
카드 안 서명은 `lib/draw.js` 의 `signature` · `tagline` 기본값에서 바꿉니다.

**꿈 문장 글자 수 제한** — `lib/draw.js` 맨 위의 `DREAM_MAX` (지금은 100자).
입력창과 카드가 같은 값을 쓰므로 이 한 곳만 고치면 양쪽에 함께 반영됩니다.

**글자 크기 자동 조절 범위** — `lib/draw.js` 의 `layoutText` 에 넘기는 크기 목록.
큰 값부터 시도해 다 들어가는 첫 크기를 고릅니다. 문장 띠가 차지할 수 있는 최대 높이는
`CAPTION_MAX_H` · `OVERLAY_MAX_H` 입니다.

**카드 색과 그림** — `lib/draw.js`
바탕 수채화 얼룩은 `blob(...)` 다섯 줄, 고양이 그림은 `drawCat` 함수입니다.

**카드 크기** — `lib/draw.js` 맨 위의 `CARD_W` / `CARD_H`
지금은 1080×1920(9:16)입니다. 정사각형으로 쓰려면 1080×1080으로 바꾸고 각 요소의 y 좌표를 조정하세요.
